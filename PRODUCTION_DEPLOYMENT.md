## 🌐 Render.com Deployment

### Pre-requisites
- Render.com account (Pro plan recommended for WebSocket support)
- Domain name pointed to Render
- SSL certificate (Render provides automatic SSL)
- Environment variables configuration

### Step 1: Backend Service Deployment

#### Create `render.yaml` in project root
```yaml
services:
  # Web Service - Main API Backend
  - type: web
    name: forex-ai-backend
    env: python
    buildCommand: pip install -r backend/requirements.txt
    startCommand: gunicorn backend.app.main:app --worker-class uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000 --timeout 300
    envVars:
      - key: DATABASE_URL
        fromDatabase:
          name: forex-db
          property: connectionString
      - key: REDIS_URL
        fromService:
          type: redis
          name: forex-cache
          property: connectionString
      - key: JWT_SECRET
        sync: false
      - key: ENCRYPTION_KEY
        sync: false
      - key: OPENROUTER_API_KEY
        sync: false
      - key: WEBSOCKET_SERVER_PORT
        value: 8765
      - key: NEXT_PUBLIC_API_URL
        value: https://yourapp.onrender.com
    healthCheckPath: /api/v1/health
    plan: pro
    
  # Worker Service - Signal Processing
  - type: worker
    name: signal-processor
    env: python
    buildCommand: pip install -r backend/requirements.txt
    startCommand: python backend/trading/signal_processor.py
    envVars:
      - key: DATABASE_URL
        fromDatabase:
          name: forex-db
          property: connectionString
      - key: REDIS_URL
        fromService:
          type: redis
          name: forex-cache
          property: connectionString
      - key: OPENROUTER_API_KEY
        sync: false
    plan: pro
    
  # Commission Processing Worker
  - type: worker
    name: commission-processor
    env: python
    buildCommand: pip install -r backend/requirements.txt
    startCommand: python backend/services/commission_settlement.py
    envVars:
      - key: DATABASE_URL
        fromDatabase:
          name: forex-db
          property: connectionString
    plan: free
    
  # Static Site - Frontend
  - type: web
    name: forex-ai-frontend
    env: node
    buildCommand: cd frontend && npm run build && npm run generate-static
    startCommand: cd frontend && npm install -g serve && serve -s build -l 3000
    publishPath: frontend/out
    plan: pro
    healthCheckPath: /health

# Databases
databases:
  - name: forex-db
    plan: starter
    databaseName: forexai_prod
    user: forexai_user
    ipAllowList: []
    
  - name: forex-cache
    plan: free
    type: redis
```

## 🔄 CI/CD Pipeline

### GitHub Actions Workflow
```yaml
name: Deploy to Render

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Backend Tests
        run: |
          cd backend
          python -m venv venv
          source venv/bin/activate
          pip install -r requirements.txt
          python -m pytest tests/ -v --cov=app
      
      - name: Frontend Tests
        run: |
          cd frontend
          npm ci
          npm run test
          
      - name: Deploy to Render
        uses: johnbrett/render-action@v1.0.0
        with:
          serviceID: your-service-id
          apiKey: ${{ secrets.RENDER_API_KEY }}
          envVars: |
            JWT_SECRET=${{ secrets.JWT_SECRET }}
            OPENROUTER_API_KEY=${{ secrets.OPENROUTER_API_KEY }}
```

## 🛡️ Security Best Practices

### Input Validation
```python
# backend/app/api/v1/endpoints/auth.py
from pydantic import BaseModel, EmailStr

class UserCreate(BaseModel):
    email: EmailStr
    username: str
    password: str  # Will be hashed
    
    @validator('password')
    def validate_password(cls, v):
        if len(v) < 8:
            raise ValueError('Password must be at least 8 characters')
        return v
```
